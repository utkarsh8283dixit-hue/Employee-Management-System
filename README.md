# Employee Management System

A console-based Employee Management System developed using Java, Maven, JDBC, and MySQL.

## 📌 Project Overview

The Employee Management System is a Java-based console application designed to manage employee records in a structured and reliable way.

The application stores employee information such as:

- Employee ID
- Employee Name
- Department
- Salary

Employee records are stored permanently in a MySQL database.

## 🚀 Features

- Add Employee
- Display All Employees
- Search Employee by ID
- Update Employee Details
- Delete Employee
- Sort Employees by Salary
- Input Validation
- Exception Handling
- MySQL Database Storage
- JDBC Database Connectivity
- Maven Dependency Management

## 🛠️ Technology Stack

| Technology | Purpose |
